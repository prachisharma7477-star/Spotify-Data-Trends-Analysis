# Spotify Music Trends & Popularity Prediction
**Data Analytics Capstone | Python · Exploratory Data Analysis · Machine Learning**

## 📌 Project Overview
This project performs a comprehensive analysis of Spotify's music catalog, covering over **170,000 tracks** released between **1921 and 2020**. The objective is to identify how musical characteristics have evolved over a century and to build a predictive model that determines the factors contributing to a song's popularity.

## 🛠️ Tech Stack
- **Languages:** Python
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn, Altair, Scikit-Learn
- **Concepts:** Data Cleaning, Feature Engineering, Correlation Analysis, Time-Series Analysis

## 🚀 Key Findings
- **The Loudness War:** There is a clear upward trend in "Loudness" and "Energy" starting from the late 20th century.
- **Acoustic Shift:** Historical data shows a sharp drop in acoustic tracks during the 1950s, coinciding with the rise of rock and electronic instruments.
- **Predictive Power:** Audio features like `Danceability` and `Valence` (musical positiveness) serve as strong indicators for a track's likelihood to trend on modern playlists.

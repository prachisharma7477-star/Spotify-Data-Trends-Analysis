# Spotify Music Trends & Popularity Prediction
**Data Analytics Capstone | Python · Scikit-Learn · Altair · Seaborn**

## 📊 Project Overview
This project analyzes a massive dataset of **170,000+ Spotify tracks** spanning a century (1921–2020). The goal is to understand how music characteristics like "danceability" and "energy" have evolved and to build a model that predicts song popularity.

## 🚀 Key Features
- **Historical Trends:** Visualized how musical audio features changed over 100 years.
- **Genre Insights:** Analyzed audio fingerprints for 3,000+ genres.
- **Popularity Prediction:** Developed a Machine Learning model using **Scikit-Learn** to forecast a song's success based on its technical attributes.
- **Interactive Visualizations:** Used **Altair** and **Seaborn** for deep-dive data storytelling.

## 🛠️ Tech Stack
- **Languages:** Python
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn, Altair, Scikit-Learn
- **Data Source:** Spotify Web API

## 📈 Key Findings
- Identified a significant correlation between "Energy" and "Loudness" in modern music.
